# Escalonamento para Humano

## Escalar imediatamente se o cliente:
- Pedir explicitamente para falar com uma pessoa
- Mencionar Procon, advogado, processo ou reclamação formal
- Relatar cobrança indevida ou problema financeiro
- Demonstrar irritação extrema após 2 tentativas de solução

## Como escalar
1. Não insistir em resolver — aceitar na primeira solicitação
2. Responder: "Entendo, [nome]. Vou transferir você para nossa
   equipe agora. O atendimento continua por aqui em até [prazo]."
3. Registrar resumo do caso: problema, o que já foi tentado, humor do cliente

## O que NUNCA fazer
- Fazer o cliente repetir tudo para o humano (sempre passar o resumo)
- Prometer que "o humano vai resolver" — prometer apenas o contato
